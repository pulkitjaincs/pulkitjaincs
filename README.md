## ⚡ Flagship Systems & Applications

### 🚄 01. AeroRail — Intelligent Rail Booking & Transit Engine
> **Status:** `Active / In Progress` &nbsp;|&nbsp; **Repo:** [pulkitjaincs/AeroRail](https://github.com/pulkitjaincs/AeroRail)

High-performance 9-microservice monorepo architecture engineered for multi-hop transit resolution and high-concurrency seat booking.

```
┌───────────────────────────────────────────────────────────────────────────────────┐
│ Architecture : 9 Microservices Monorepo (pnpm Workspaces + Express 5)             │
│ API Gateway  : Kong Gateway with RS256 JWT Auth, Rate Limiting & Circuit Breaking │
│ Graph Engine : Neo4j Graph DB (<400ms journey resolution across 50+ stations)     │
│ Concurrency  : Redis Redlock + PostgreSQL FOR UPDATE locks (Zero double-bookings) │
│ Event-Driven : Kafka (KRaft) Transactional Outbox for async PNR confirmation      │
│ Web Client   : Next.js 15 PWA with offline caching & interactive seat selection   │
└───────────────────────────────────────────────────────────────────────────────────┘
```
`TypeScript` `Next.js 15` `Neo4j` `PostgreSQL` `Redis` `Kafka` `Kong` `Docker`
